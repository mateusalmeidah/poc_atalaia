# Structure - PoC 0.1

Use separação simples:

- `src/atalaia_governanca/`: código do motor;
- `tests/`: testes;
- `examples/`: casos sintéticos;
- `spec/decisoes/`: GOV-ADRs gerados;
- `.kiro/specs/`: spec produzida pelo Kiro;
- `saida_para_chatgpt/`: relatório final para revisão externa.

Não misturar arquivos gerados de evidência com código-fonte.

Os GOV-ADRs devem ser legíveis por humanos e estáveis em formato.
