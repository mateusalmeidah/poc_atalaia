# Regras de governança ATALAIA para a PoC

1. Spec antes de implementação.
2. Decisões sensíveis exigem revisão humana.
3. Evidência deve ser gerada junto com o trabalho.
4. Automação determinística para regras e validações.
5. Casos ambíguos devem falhar para o lado seguro: escalar, não decidir.
6. A recomendação do motor deve ser explicável.
7. Dados reais são proibidos.
8. Nunca afirmar conformidade legal automática.
9. Toda exceção deve aparecer no GOV-ADR.
10. A PoC deve permanecer desacoplada do ATALAIA oficial.
