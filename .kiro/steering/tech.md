# Technology - PoC 0.1

## Stack preferida

- Python 3.11+
- pytest
- biblioteca padrão sempre que possível
- JSON para exemplos de entrada
- Markdown para GOV-ADR e relatórios

## Restrições

- sem APIs externas;
- sem LLM remoto;
- sem banco de dados;
- sem serviços cloud;
- sem Presidio/ARX nesta PoC;
- evitar dependências que não tragam valor claro.

## Qualidade

- type hints;
- funções pequenas;
- testes unitários;
- mensagens de erro claras;
- execução reproduzível.
